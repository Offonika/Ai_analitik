Проверить отчет

Система выберет главное действие после загрузки отчета.

Файл сопоставления WB ↔ 1C TXT/TSV/CSV из списка «Сопоставление товаров» в 1С.
Как выгрузить файл из 1С
  1. Откройте раздел «Маркетплейс».
  2. В блоке «Обработки» выберите «Сопоставление товаров».
  3. Проверьте профиль нужного WB-кабинета или ИП.
  4. В таблице нажмите «Еще» → «Вывести список...».
  5. В списке нажмите кнопку сохранения и выберите текстовый формат TXT, TSV или CSV.

Если 1С предлагает «Табличный документ (*.mxl)», смените тип файла перед сохранением. MXL сюда не загружаем.

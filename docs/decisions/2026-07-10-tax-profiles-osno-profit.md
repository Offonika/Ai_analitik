# Налоговые профили, ОСНО и прибыль до НДФЛ

Статус: **accepted**. Решение действует для новых отчетов, построенных по
профильной налоговой методике.

## Решение

- Налоги рассчитываются только при наличии явного налогового профиля
  организации 1С и подтвержденных ставок.
- Для ОСНО товарная выручка и расходы приводятся к базе без НДС, входной НДС
  принимается только по подтвержденным данным, а результат показывается как
  `НДС к уплате`.
- Управленческий результат после расходов WB и себестоимости называется
  `Управленческая прибыль WB`.
- После перехода к P&L без НДС и учета применимого профильного налога результат
  называется `прибыль до НДФЛ`. `НДС к уплате` показывается отдельной сверкой и
  не вычитается повторно. НДФЛ предпринимателя не включается без отдельного
  согласованного правила.
- Если профиль, ставка или обязательный налоговый источник отсутствует,
  налоговые показатели и `прибыль до НДФЛ` остаются неопределенными. Ноль
  не подставляется.
- Формула `НДС 5/105 + УСН 1%` сохраняется только как legacy-совместимость для
  отчетов, чья зафиксированная версия методики явно требует эту формулу.

## Совместимость полей

Внутренние legacy-поля можно сохранять в API и выгрузках для обратной
совместимости. Клиентские заголовки, KPI и пояснения используют только новую
семантику. Наличие legacy-поля не разрешает применять старую формулу к новому
отчету.

## Последствия

- статический Markdown не определяет налоговый профиль конкретного отчета;
- report-specific пакет берет методику и готовность из опубликованного
  `report_run`;
- DB-first пересборка и публикационный gate разрешают налоговый профиль через
  один и тот же контур: профиль текущего read-only снимка 1С, затем действующее
  аудируемое ручное исключение для организации и даты, затем `missing`;
- источник, период действия и признак ручного исключения сохраняются в строках
  нового отчета; наличие исключения только в интерфейсе без его применения в
  расчете не считается подтвержденным налоговым профилем;
- отсутствие налогового профиля блокирует статус полной готовности налоговых
  KPI, но не искажает фактические неналоговые показатели;
- решение 18.06.2026 помечено `superseded` и остается историческим документом.

# Назначение

Этот runbook нужен администратору или разработчику 1С, чтобы опубликовать
маленький read-only HTTP-сервис для выгрузки формы `Сопоставление товаров` из
расширения `ИС_Маркетплейс`.

Сервис читает только маппинг WB/Ozon -> 1С и возвращает JSON. Он не должен
читать токены WB/Ozon, настройки обмена, документы, цены или себестоимость.

Для клиентских внедрений предпочтительный путь - собрать и установить отдельное
расширение `.cfe` по инструкции
`docs/runbooks/onec-marketplace-mapping-client-extension.md`. Этот документ
остается техническим описанием самого HTTP-сервиса и его модуля.

# Что создать в 1С

Создать отдельное расширение или доработку с HTTP-сервисом:

- имя HTTP-сервиса: `WBUnitEconomics`;
- корневой URL после публикации: `/hs/wb-unit-economics/v1`;
- шаблон `health`, метод `GET`, обработчик `HealthGet`;
- шаблон `mapping`, метод `GET`, обработчик `MappingGet`.

Итоговые методы:

```text
GET /hs/wb-unit-economics/v1/health
GET /hs/wb-unit-economics/v1/mapping
GET /hs/wb-unit-economics/v1/mapping?limit=100
GET /hs/wb-unit-economics/v1/mapping?marketplace=ozon&limit=100
```

Если база опубликована с префиксом публикации, полный URL будет зависеть от
сервера 1С, например:

```text
https://example.1cfresh.com/<base>/hs/wb-unit-economics/v1/mapping?limit=100
```

# Права пользователя

Создать отдельного пользователя, например `offonika_readonly`.

Минимальные права:

- вход через опубликованный HTTP-сервис;
- чтение `РегистрСведений.ИС_WB_СоответствиеРазмеров`;
- чтение `Справочник.ИС_WB_РазмерыНоменклатур`;
- чтение `Справочник.ИС_WB_Номенклатура`;
- чтение `РегистрСведений.ИС_WB_ШтрихкодыРазмеров`;
- чтение `РегистрСведений.ИС_Ozon_СоответствиеХарактеристик`;
- чтение `Справочник.ИС_Ozon_Номенклатура`;
- чтение стандартной `Справочник.Номенклатура` и
  `Справочник.ХарактеристикиНоменклатуры` только для ссылок из регистра
  соответствия.

Запрещено:

- запись, изменение, удаление и проведение;
- чтение объектов с WB/Ozon API token, password, secret или настройками профилей;
- публикация всего расширения через OData только ради этого маппинга.

# Объекты расширения

По выгрузке расширения `ИС_Маркетплейс 3.5.57.0` нужны эти поля:

| Объект 1С | Поля |
| --- | --- |
| `РегистрСведений.ИС_WB_СоответствиеРазмеров` | `Профиль`, `РазмерWB`, `Номенклатура`, `Характеристика`, `Упаковка` |
| `Справочник.ИС_WB_РазмерыНоменклатур` | владелец `ИС_WB_Номенклатура`, `Профиль`, `techSize`, `wbSize`, `price` |
| `Справочник.ИС_WB_Номенклатура` | `Код`, `Наименование`, `Профиль`, `vendorCode`, `Бренд` |
| `РегистрСведений.ИС_WB_ШтрихкодыРазмеров` | `Профиль`, `Размер`, `Штрихкод` |
| `РегистрСведений.ИС_Ozon_СоответствиеХарактеристик` | `НоменклатураOzon`, `Номенклатура`, `Характеристика`, `Упаковка` |
| `Справочник.ИС_Ozon_Номенклатура` | `Профиль`, `Код`, `Наименование`, `offer_id`, `sku`, `sku_fbs`, `sku_fbo`, `Штрихкод` |

Перед установкой на рабочую базу разработчик 1С должен один раз открыть
конфигуратор и проверить имена полей, потому что поставщик расширения может
изменить структуру в новой версии.

# Шаблон модуля HTTP-сервиса

Канонический исходник модуля лежит в
`extensions/offonika/src/HTTPServices/WBUnitEconomics/Ext/Module.bsl`.
Актуальный код нужно переносить из исходника расширения, а не из чата или
документации. В модуле должны быть два режима `MappingGet`: по умолчанию WB и
`marketplace=ozon` для Ozon-маппинга.

```bsl
Функция HealthGet(Запрос)

	Данные = Новый Структура;
	Данные.Вставить("schema_version", "1");
	Данные.Вставить("source", "1c_marketplace_http");
	Данные.Вставить("status", "ok");
	Данные.Вставить("generated_at", ФорматДатаJSON(ТекущаяДатаСеанса()));

	Возврат JsonОтвет(200, Данные);

КонецФункции

Функция MappingGet(Запрос)

	Лимит = ЛимитИзЗапроса(Запрос, 10000);
	Строки = Новый Массив;

	Запрос1С = Новый Запрос;
	Запрос1С.Текст =
	"ВЫБРАТЬ ПЕРВЫЕ &Лимит
	|	Соответствие.Профиль КАК Профиль,
	|	Соответствие.РазмерWB КАК РазмерWB,
	|	Соответствие.РазмерWB.Владелец КАК НоменклатураWB,
	|	Соответствие.РазмерWB.Владелец.Код КАК NmId,
	|	Соответствие.РазмерWB.Владелец.vendorCode КАК VendorCode,
	|	Соответствие.РазмерWB.techSize КАК TechSize,
	|	Соответствие.РазмерWB.wbSize КАК WbSize,
	|	Штрихкоды.Штрихкод КАК Barcode,
	|	Соответствие.Номенклатура КАК Номенклатура1С,
	|	Соответствие.Номенклатура.Код КАК OnecCode,
	|	Соответствие.Номенклатура.Артикул КАК OnecArticle,
	|	Соответствие.Номенклатура.Наименование КАК OnecName,
	|	Соответствие.Характеристика КАК Характеристика1С,
	|	Соответствие.Характеристика.Наименование КАК OnecCharacteristic
	|ИЗ
	|	РегистрСведений.ИС_WB_СоответствиеРазмеров КАК Соответствие
	|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.ИС_WB_ШтрихкодыРазмеров КАК Штрихкоды
	|		ПО Штрихкоды.Профиль = Соответствие.Профиль
	|			И Штрихкоды.Размер = Соответствие.РазмерWB
	|ГДЕ
	|	Соответствие.Активность";

	Запрос1С.УстановитьПараметр("Лимит", Лимит + 1);

	Попытка
		Выборка = Запрос1С.Выполнить().Выбрать();
	Исключение
		Возврат ОшибкаJson(500, "query_failed");
	КонецПопытки;

	НомерСтроки = 0;
	Пока Выборка.Следующий() Цикл
		НомерСтроки = НомерСтроки + 1;

		Если НомерСтроки > Лимит Тогда
			Прервать;
		КонецЕсли;

		Строка = Новый Структура;
		Строка.Вставить("profile_key", СсылкаКлюч(Выборка.Профиль));
		Строка.Вставить("nm_id", ЧислоИлиNull(Выборка.NmId));
		Строка.Вставить("vendor_code", СтрокаИлиПусто(Выборка.VendorCode));
		Строка.Вставить("tech_size", СтрокаИлиПусто(Выборка.TechSize));
		Строка.Вставить("wb_size", СтрокаИлиПусто(Выборка.WbSize));
		Строка.Вставить("barcode", СтрокаИлиПусто(Выборка.Barcode));
		Строка.Вставить("onec_item_id", СсылкаКлюч(Выборка.Номенклатура1С));
		Строка.Вставить("onec_code", СтрокаИлиПусто(Выборка.OnecCode));
		Строка.Вставить("onec_article", СтрокаИлиПусто(Выборка.OnecArticle));
		Строка.Вставить("onec_name", СтрокаИлиПусто(Выборка.OnecName));
		Строка.Вставить("onec_characteristic_id", СсылкаКлюч(Выборка.Характеристика1С));
		Строка.Вставить("onec_characteristic", СтрокаИлиПусто(Выборка.OnecCharacteristic));

		Если ЗначениеЗаполнено(Выборка.Номенклатура1С) Тогда
			Строка.Вставить("status", "matched");
		Иначе
			Строка.Вставить("status", "missing");
		КонецЕсли;

		Строки.Добавить(Строка);
	КонецЦикла;

	Данные = Новый Структура;
	Данные.Вставить("schema_version", "1");
	Данные.Вставить("source", "1c_marketplace_http");
	Данные.Вставить("generated_at", ФорматДатаJSON(ТекущаяДатаСеанса()));
	Данные.Вставить("timezone", "Europe/Moscow");
	Данные.Вставить("row_count", Строки.Количество());
	Данные.Вставить("truncated", НомерСтроки > Лимит);
	Данные.Вставить("rows", Строки);

	Возврат JsonОтвет(200, Данные);

КонецФункции

Функция ЛимитИзЗапроса(Запрос, ЛимитПоУмолчанию)

	Лимит = ЛимитПоУмолчанию;
	Если Запрос.ПараметрыЗапроса.Свойство("limit") Тогда
		Попытка
			Лимит = Число(Запрос.ПараметрыЗапроса["limit"]);
		Исключение
			Лимит = ЛимитПоУмолчанию;
		КонецПопытки;
	КонецЕсли;

	Если Лимит < 1 Тогда
		Лимит = ЛимитПоУмолчанию;
	КонецЕсли;

	Если Лимит > 50000 Тогда
		Лимит = 50000;
	КонецЕсли;

	Возврат Лимит;

КонецФункции

Функция JsonОтвет(КодСостояния, Данные)

	ЗаписьJSON = Новый ЗаписьJSON;
	ЗаписьJSON.УстановитьСтроку();
	ЗаписатьJSON(ЗаписьJSON, Данные);
	Тело = ЗаписьJSON.Закрыть();

	Ответ = Новый HTTPСервисОтвет(КодСостояния);
	Ответ.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
	Ответ.УстановитьТелоИзСтроки(
		Тело,
		КодировкаТекста.UTF8,
		ИспользованиеByteOrderMark.НеИспользовать
	);

	Возврат Ответ;

КонецФункции

Функция ОшибкаJson(КодСостояния, КодОшибки)

	Данные = Новый Структура;
	Данные.Вставить("schema_version", "1");
	Данные.Вставить("source", "1c_marketplace_http");
	Данные.Вставить("status", "error");
	Данные.Вставить("error", КодОшибки);

	Возврат JsonОтвет(КодСостояния, Данные);

КонецФункции

Функция СсылкаКлюч(Значение)

	Если Не ЗначениеЗаполнено(Значение) Тогда
		Возврат "";
	КонецЕсли;

	Попытка
		Возврат Строка(Значение.УникальныйИдентификатор());
	Исключение
		Возврат "";
	КонецПопытки;

КонецФункции

Функция СтрокаИлиПусто(Значение)

	Если Значение = Неопределено Или Значение = Null Тогда
		Возврат "";
	КонецЕсли;

	Возврат СокрЛП(Строка(Значение));

КонецФункции

Функция ЧислоИлиNull(Значение)

	Если Значение = Неопределено Или Значение = Null Тогда
		Возврат Null;
	КонецЕсли;

	Попытка
		Возврат Число(Значение);
	Исключение
		Возврат Null;
	КонецПопытки;

КонецФункции

Функция ФорматДатаJSON(ДатаЗначение)

	Возврат Формат(ДатаЗначение, "ДФ=yyyy-MM-ddTHH:mm:ss") + "+03:00";

КонецФункции
```

# Проверка в 1С

После публикации проверить:

```bash
curl -u '<user>:<password>' \
  'https://<host>/<base>/hs/wb-unit-economics/v1/health'

curl -u '<user>:<password>' \
  'https://<host>/<base>/hs/wb-unit-economics/v1/mapping?limit=10'

curl -u '<user>:<password>' \
  'https://<host>/<base>/hs/wb-unit-economics/v1/mapping?marketplace=ozon&limit=10'
```

Пароль не вставлять в документацию, чат или Git. Команды выше являются шаблоном.

Ожидаемый `health`:

```json
{
  "schema_version": "1",
  "source": "1c_marketplace_http",
  "status": "ok",
  "generated_at": "2026-07-04T12:00:00+03:00",
  "marketplaces": ["wb", "ozon"]
}
```

Ожидаемый WB `mapping`:

```json
{
  "schema_version": "1",
  "source": "1c_marketplace_http",
  "marketplace": "wb",
  "generated_at": "2026-07-04T12:00:00+03:00",
  "timezone": "Europe/Moscow",
  "row_count": 10,
  "truncated": false,
  "rows": []
}
```

Ожидаемый Ozon `mapping`:

```json
{
  "schema_version": "1",
  "source": "1c_marketplace_http",
  "marketplace": "ozon",
  "generated_at": "2026-07-04T12:00:00+03:00",
  "timezone": "Europe/Moscow",
  "row_count": 10,
  "truncated": false,
  "rows": []
}
```

# Проверка безопасности

В ответе не должно быть строк и полей:

- `token`;
- `password`;
- `secret`;
- `apiKey`;
- `clientId`;
- `Authorization`;
- настройки профиля WB/Ozon;
- raw JSON от WB/Ozon.

Если такие поля появились, сервис нельзя подключать к проекту до удаления этих
полей и ротации затронутых секретов.

# Как передать нам доступ

Передать только безопасные сведения:

```text
Тип доступа: 1С HTTP-сервис read-only
URL health: https://<host>/<base>/hs/wb-unit-economics/v1/health
URL mapping: https://<host>/<base>/hs/wb-unit-economics/v1/mapping
URL Ozon mapping: https://<host>/<base>/hs/wb-unit-economics/v1/mapping?marketplace=ozon
Пользователь: offonika_readonly
Пароль: передан отдельно безопасным способом
IP нашего сервера в белом списке: 102.129.178.65
Ограничение: только GET, только чтение
```

Содержимое ответа `mapping` не отправлять в чат, если там реальные клиентские
товары. Для проверки достаточно `row_count`, списка полей и нескольких
обезличенных строк.

# Rollback

Если сервис мешает работе 1С или вызывает вопросы безопасности:

1. Снять публикацию HTTP-сервиса или отключить пользователя `offonika_readonly`.
2. Вернуться к ручной выгрузке TXT в `data/onec_marketplace_mapping/`.
3. Проверить, что проект не использует новый URL в runtime настройках.
